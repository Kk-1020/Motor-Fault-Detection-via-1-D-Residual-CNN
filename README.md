# Motor-Fault-Detection-via-1-D-Residual-CNN
A lightweight 1D residual CNN trained from scratch in PyTorch to classify motor faults from 3 axis vibration data into 4 categories. Features dilated convolutions, global average pooling, and cosine annealing, achieving 95.9% test accuracy with only 186K parameters, designed for INT8 deployment on Texas Instruments embedded DSPs.
